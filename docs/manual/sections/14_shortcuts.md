### Tools

| Shortcut | Tool |
| --- | --- |
| <kbd>V</kbd> / <kbd>1</kbd> | Navigate |
| <kbd>S</kbd> / <kbd>2</kbd> | Select |
| <kbd>D</kbd> / <kbd>3</kbd> | Distance |
| <kbd>A</kbd> / <kbd>4</kbd> | Area |
| <kbd>N</kbd> / <kbd>5</kbd> | Note |
| <kbd>G</kbd> / <kbd>6</kbd> | Annotation |

### General

| Shortcut | Action |
| --- | --- |
| <kbd>Esc</kbd> | Cancel the in-progress action; press again to return to Navigate |
| <kbd>Delete</kbd> | Delete the currently selected Note/Annotation/measurement (Navigate tool) |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / Redo |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open PLY… |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save Project |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save Project As… |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Open Project… |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Export PDF… |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select All (every visible point) |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Exit |
